# Forge2D

**A lightweight, code-first 2D game editor for Windows.**

Forge2D is an independent game-development tool created by **Ilyas**. It combines project management, code editing, building, and running into one focused workflow.

> **Forge2D is proprietary software and is not open source.**

## ✨ Features

* 🧩 Code-first 2D game development
* ⚙️ ForgeLink build workflow
* 💻 C++ project support
* 📁 Project management
* 🔨 Build and run from the editor
* 🪶 Lightweight Windows application
* 🚀 Designed for fast iteration

## 🔧 ForgeLink

ForgeLink is the build workflow used by Forge2D to compile project source files and produce the game's executable.

ForgeLink works with supported C++ compilers installed on the user's system.

See the [ForgeLink documentation](docs/forgelink.md).
