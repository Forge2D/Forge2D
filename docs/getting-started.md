# Getting Started

## Requirements

Forge2D currently targets:

* Windows 10 or later
* 64-bit Windows
* A supported C++ compiler

Forge2D uses the compiler installed on your system for project builds.

## 1. Download Forge2D

Download the latest release from:

https://forge2d.pages.dev

Extract the downloaded archive to a location of your choice.

## 2. Create a project

Open Forge2D and create a new project.

Forge2D creates a project directory containing the project configuration and source files.

## 3. Edit your project

Use the editor to work on your project's source files.

A basic project contains a `project.forge` file and one or more C++ source files.

## 4. Build

Use the Build command inside Forge2D.

ForgeLink reads the project configuration and invokes the configured C++ compiler.

## 5. Run

After a successful build, use Run to launch your game.

## Troubleshooting

If a build fails:

1. Check that a supported C++ compiler is installed.
2. Check the ForgeLink build output.
3. Make sure your source files exist.
4. Check that your `project.forge` configuration is valid.

For additional information, see the ForgeLink documentation.
