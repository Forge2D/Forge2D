# Forge2D Examples

This directory contains small example projects demonstrating how Forge2D projects are structured.

These examples are provided for learning and experimentation.

They do **not** contain the Forge2D editor source code.

## Available examples

### HelloWorld

A minimal Forge2D project demonstrating:

* `project.forge`
* A C++ source file
* The basic ForgeLink workflow

Open the [`HelloWorld`](HelloWorld/) directory to get started.
