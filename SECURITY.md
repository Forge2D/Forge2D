# Security Policy

## Reporting a vulnerability

If you believe you have discovered a security vulnerability in Forge2D, please do not publicly disclose the vulnerability before it has been investigated.

Please report security issues through the official Forge2D project contact channels.

Website:

https://forge2d.pages.dev

## What to include

When reporting a security issue, please include:

* Forge2D version
* Windows version
* Description of the issue
* Steps required to reproduce it
* Expected behavior
* Actual behavior
* Any relevant files or screenshots

Please do not include passwords, private keys, personal information, or other sensitive information.

## Supported versions

Security fixes are primarily provided for the latest stable release.

Older releases may not receive security updates.

## Release verification

Official releases may include SHA-256 checksums so users can verify that their downloaded files match the published release.
